# Pytest Example

A simple example of using pytest for testing python code.

#### Setup
- Ensure that you have `uv` installed. You can find more about uv here: [uv docs](https://docs.astral.sh/uv/)
- Clone this repo.
- Then simply run `uv sync`.
  - This will create a virtual environment via venv if it does not exist
- Activate the venv: `.venv\Scripts\activate` (_be sure to adjust the slashes "`\`" for your os_)
- Now you can run `pytest` on the terminal and you should see output.
